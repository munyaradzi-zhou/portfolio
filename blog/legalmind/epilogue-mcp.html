Epilogue: when the user is another AI

LegalMind on Azure · epilogue

TL;DR — LegalMind is also an MCP server, so Claude, Copilot or an Azure AI Foundry agent can use the legal knowledge base as a tool. The server is a thin client of the same API, so every guardrail still applies — and the answer carries its grounding label, so the calling agent can tell a verified answer from one it should flag.

The Model Context Protocol (MCP) is an open standard for giving AI agents tools: a server describes its tools — name, description, argument schema — and any MCP-capable host can discover and call them. LegalMind exposes four:

Tool Does
ask_legal_question A grounded answer with citations and a grounding label; pass the session ID back for follow-ups
search_legal_documents Hybrid search for passages, optionally by document type
ingest_document Add a local PDF, DOCX, TXT or image to the knowledge base
list_agents The specialist agents and their tools 
claude mcp add legalmind --env LEGALMIND_API_URL=https://<your-api> -- legalmind-mcp

Three design choices

A thin client, not a second backend. The MCP server calls the same REST API as the web interface. Content Safety, PII detection, the groundedness check, rate limits and the audit log all apply to agents exactly as they apply to people. There's one code path to secure and fix.

Descriptions are prompts. The host puts each tool's description in the model's context, and that text decides when the model uses which tool. "Use search_legal_documents to find where something is written; use ask_legal_question for an answer" is an instruction to a model as much as documentation for a person.

The grounding label travels with the answer. After Part 4, every answer says whether it's backed by the documents. Through MCP that becomes "grounding": "not_grounded" in the tool result — so a calling agent can say "LegalMind couldn't confirm this from the documents" instead of repeating an unsupported claim as fact. Guardrails don't stop mattering because the user is a model; they matter more, because a model will pass the answer on without hesitation.

What changes when an agent is the user

An MCP server is an API whose caller is a model, and models can be manipulated. Least privilege, validated arguments (document types are an enumeration, result counts are capped, uploads are size- and type-limited), every call in the audit log, and a human approving anything that writes. The same rules as any API — applied a little more strictly.

LegalMind AI is open source: github.com/munyaradzi-zhou/LegalMind-AI. The sample organisation and documents are fictional; LegalMind is a demonstration, not legal advice.
